## Usage

```bash
./cub3d map.cub
```
## Map Format
The map format is a simple text file with the following structure:

```
R
Resolution (width height)
NO
North texture path
SO
South texture path
WE
West texture path
EA
East texture path
F
Floor color (R G B)
C
Ceiling color (R G B)
1
Map data (1 for wall, 0 for empty space)
```
## Example Map
```
R
800 600
NO ./textures/north.xpm
SO ./textures/south.xpm
WE ./textures/west.xpm
EA ./textures/east.xpm
F 220 220 220
C 100 100 100
    
1111111111111111
1000000000000001
1000000000000001
1000000000000001
1000000000000001
1000000000000001
1111111111111111
```
